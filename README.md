# 🎮 Simon Game

A simple and interactive **Simon Game** built using **HTML, CSS, and JavaScript**.

The game tests your memory by showing a sequence of colors. Your goal is to remember and repeat the sequence correctly. As you progress through the levels, the sequence becomes longer and more challenging.

:## 🚀 Live Demo

**Live Demo:** 
 https://iamabhiaryan.github.io/Simon-game/

## 📸 Features

* 🎨 Four interactive colored buttons
* 🧠 Memory-based gameplay
* 📈 Increasing difficulty with each level
* 🏆 Score tracking
* 🔄 Restart / Play Again functionality
* ✨ Button flash animations
* 📱 Responsive design for mobile and desktop
* ❌ Game-over detection

## 🛠️ Technologies Used

* **HTML5** – Structure of the game
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Game logic, random sequence generation, user interaction, and score management
